# Divider

A hairline rule, optionally with a centred label. Separates groups that are related but distinct.

## Usage

```tsx
<Divider />
<Divider label="Or continue with" />
<Divider orientation="vertical" />
```

## Guidance

- Prefer spacing over rules. Add a Divider only when proximity alone is ambiguous.
- `subtle` for dense groupings inside a card.
