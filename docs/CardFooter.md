# CardFooter

Action row of a Card. Right-aligns its children and adds a top hairline.

## Usage

```tsx
<CardFooter>
  <Button variant="ghost" size="sm">Dismiss</Button>
  <Button size="sm">View report</Button>
</CardFooter>
```

## Guidance

- Order actions least- to most-important, left to right; the primary sits last.
- Keep it to two actions; more belongs in a menu.
